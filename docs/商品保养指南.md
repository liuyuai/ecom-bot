# 商品保养指南

## 数码产品

### 手机
- 避免长时间高负荷运行（游戏时注意散热）
- 每月进行一次完整充放电（用到 20% 以下再充满）
- 避免在极端温度下使用（0°C 以下或 45°C 以上）
- 建议使用原装充电器和数据线

### 笔记本电脑
- 定期清理风扇灰尘（每 6-12 个月）
- 避免在床上、沙发上使用（堵塞散热口）
- 电池长期不用时保持 50% 电量存放
- 屏幕用专用清洁布擦拭，避免酒精

### 耳机
- 使用后及时放入充电盒
- 定期清洁耳塞（用酒精棉片）
- 避免拉扯线材
- 防水耳机也不建议佩戴游泳

## 服饰类

### 洗涤
- 查看洗水标，按说明洗涤
- 深色衣物首次单独冷水洗涤
- 羊毛、真丝建议干洗
- 牛仔裤翻面洗涤，减少褪色

### 收纳
- 长期存放前清洗干净
- 衣物晾干后再收纳，防止发霉
- 皮衣、皮鞋需放干燥剂
- 避免阳光直射存放（防止褪色）

## 食品类

### 保存
- 常温食品：阴凉干燥处，避免阳光直射
- 冷藏食品：0-4°C，开封后尽快食用
- 冷冻食品：-18°C 以下，解冻后不可再次冷冻
- 注意保质期，临期食品优先食用

## 售后保养服务
- 数码产品：厂家保修期内免费维修
- 服饰类：质量问题 30 天内可退换
- 食品类：变质问题凭照片可退款或补发
- 具体保修政策以商品详情页为准
