# 发票开具说明

## 发票类型

### 电子普通发票
- 默认开具电子普通发票
- 下单时勾选"需要发票"即可
- 支付成功后 1-2 个工作日内开具
- 可在订单详情中下载 PDF
- 与纸质发票具有同等法律效力

### 增值税专用发票
- 仅支持企业用户
- 需提供企业名称、税号、注册地址、电话、开户行及账号
- 审核通过后 3-5 个工作日内开具并邮寄
- 邮费由商家承担

## 开票规则

1. 发票金额为实际支付金额（不含优惠券抵扣部分）
2. 一张订单对应一张发票，不可拆分开具
3. 发票内容默认按商品明细开具
4. 发票一经开具，不支持修改（如需重开，需先退回原发票）

## 发票抬头
- 个人：填写姓名
- 企业：填写企业全称 + 税号
- 下单时填写，支付后不可修改

## 补开发票
- 订单完成后 90 天内可申请补开
- 超过 90 天不予补开
- 联系客服提供订单号和发票信息即可

## 发票查询
- 电子发票：订单详情页直接下载
- 纸质发票：在"我的-发票管理"中查看物流
- 如未收到，联系客服查询
