# 账户安全指南

## 密码安全

### 设置要求
- 长度 8-20 位
- 必须包含字母和数字
- 建议包含特殊符号
- 不要使用生日、手机号、连续数字等弱密码

### 修改密码
- 路径：我的-设置-账户安全-修改密码
- 需验证原密码
- 修改后所有设备需重新登录

## 登录保护

### 短信验证
- 异地登录自动触发短信验证
- 可在设置中开启"每次登录都需验证"

### 设备管理
- 可查看当前登录设备列表
- 支持远程下线异常设备
- 路径：我的-设置-账户安全-设备管理

## 绑定与解绑

### 手机号绑定
- 注册时自动绑定
- 换绑需验证原手机号 + 新手机号
- 如原手机号已停用，联系客服人工审核（需提供身份证）

### 第三方账号绑定
- 支持微信、支付宝、QQ 快捷登录
- 绑定后可一键登录
- 解绑后需用手机号+密码登录

## 账户被盗处理

1. 立即修改密码
2. 下线所有设备
3. 检查订单和支付记录
4. 如有异常订单，立即联系客服冻结
5. 必要时报警

## 安全提醒
- 不要在公共设备上勾选"记住密码"
- 不要向任何人透露验证码
- 客服不会索要密码和验证码
- 定期检查登录设备和订单记录
