# 支付方式说明

## 支持的支付方式

### 在线支付
- 支付宝：支持余额、花呗、银行卡、信用卡
- 微信支付：支持零钱、绑定银行卡、信用卡
- 银联云闪付：支持所有银联卡
- 数字人民币：部分城市试点中

### 货到付款
- 仅支持部分城市和商品
- 需支付 5 元货到付款服务费
- 签收时现金或刷卡支付

### 分期付款
- 花呗分期：支持 3/6/12 期
- 信用卡分期：支持招行、建行、工行等主流银行
- 分期免息活动：不定期开展，以商品页标注为准

## 支付失败处理

### 常见原因
1. 银行卡余额不足
2. 超出支付限额（单笔/单日）
3. 网络超时
4. 银行卡未开通网银或快捷支付

### 处理方式
- 支付失败后订单保留 30 分钟，超时自动取消
- 可在"我的订单"中重新发起支付
- 如已扣款但订单未更新，1-2 个工作日内自动退款

## 发票与支付凭证
- 支付成功后可在订单详情中下载电子凭证
- 如需纸质凭证，联系客服邮寄（运费到付）
