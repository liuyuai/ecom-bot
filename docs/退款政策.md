# 退款政策

## 退款条件

### 可退款场景
1. 商品质量问题（破损、故障、与描述不符）
2. 7天无理由退货（商品完好、不影响二次销售）
3. 商家发错货、漏发货
4. 商品过期或临期（食品类）
5. 未发货订单可直接取消退款

### 不可退款场景
1. 定制类商品（非质量问题）
2. 贴身内衣、食品类（非质量问题）
3. 已使用且影响二次销售的商品
4. 虚拟商品（充值卡、电子券等）
5. 超过售后期限（签收超过15天）

## 退款时效

| 环节 | 时效 |
|------|------|
| 申请退款 | 签收后7天内（无理由）/ 15天内（质量问题） |
| 商家审核 | 24小时内 |
| 退货签收检验 | 1-3个工作日 |
| 退款到账 | 检验无误后1-3个工作日 |

## 退款到账时间（按支付方式）

| 支付方式 | 到账时间 |
|---------|---------|
| 支付宝 | 1-2小时 |
| 微信支付 | 1-2小时 |
| 银行卡 | 1-3个工作日 |
| 信用卡 | 3-7个工作日（退回信用卡额度） |
| 花呗/白条 | 1-3个工作日（恢复额度） |

## 退款金额计算

### 全额退款
- 质量问题、发错货：全额退款，含运费
- 未发货订单：全额退款

### 部分退款
- 7天无理由退货：退款金额 = 商品金额 - 退货运费
- 商品部分使用：按完好比例退款
- 套装商品部分退货：按单件价格退款

### 不退款部分
- 优惠券抵扣金额：不退现金，退回至账户优惠券
- 积分抵扣金额：退回积分账户
- 运费险：理赔金额直接到账，不计入商品退款
- 已使用的服务费/安装费：不予退还

## 退款流程

1. 用户在订单详情页点击"申请退款"
2. 选择退款原因并上传凭证（照片/视频）
3. 商家24小时内审核
4. 审核通过后，用户寄回商品（质量问题商家承担运费）
5. 商家签收并检验商品
6. 检验无误后1-3个工作日内原路退款

## 退款查询
- 订单详情页可查看退款进度
- 退款到账后会有短信和APP推送通知
- 超过3个工作日未到账，联系客服查询

## 特殊情况

### 仅退款不退货
- 商品价值低于运费（如9.9元商品）
- 商品已破损无法寄回
- 商家同意仅退款

### 退款被拒
- 商家拒绝退款后，用户可在3天内申请平台介入
- 平台介入后3-5个工作日给出仲裁结果
- 对仲裁结果不满可向消费者协会投诉
