# 售后政策

## 退换货政策

### 7天无理由退货
- 签收后7天内，商品完好、不影响二次销售，可申请无理由退货
- 退货运费由买家承担（质量问题除外）
- 定制类商品、贴身内衣、食品类不支持7天无理由退货

### 15天换货
- 签收后15天内，商品存在质量问题，可申请免费换货
- 换货运费由商家承担

### 质量问题保修
- 电子产品享受1年质保
- 质保期内非人为损坏，免费维修或更换
- 人为损坏不在保修范围内

## 退款说明

- 退货商品签收并检验无误后，1-3个工作日内原路退款
- 退款到账时间：支付宝1-2小时，微信1-2小时，银行卡1-3个工作日
- 优惠券抵扣部分不退现金，退回至账户
